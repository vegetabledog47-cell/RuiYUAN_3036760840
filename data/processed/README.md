# Processed analysis data

`python code/run_all.py` writes `analysis_sample.csv` here from the authorized course input. It contains the original store-level columns, constructed employment and wage variables, and sample indicators used by the final analysis. This derived store-level file is available in the local delivery and excluded from the public repository under the course-data restriction. Reviewers regenerate it without manual editing. Aggregate results are included in `outputs/tables/` and `outputs/figures/`.
